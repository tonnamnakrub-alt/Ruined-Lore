Passive: Hunter’s Brand ( ตราประทับล่าอสุรา ) การโจมตีด้วยสกิลของเฮลซิงจะเผาผลาญบาปและประทับตรารอยแผลศักดิ์สิทธิ์ลงบนวิญญาณศัตรูทําให้การโจมตีปกติซํ้าเข้าไปในรอยแผลทําลายล้างรุนแรงขึ้นตามสภาวะบาดเจ็บของเหยื่อ
  - กลไกการทํางาน :
      · เมื่อสกิลของเฮลซิง (Q, W, E, R) สัมผัสหรือสร้างความเสียหายใส่ศัตรูจะแปะสถานะ Hunter’s Brand ไว้บนเป้าหมายนาน 4.0 วินาที
      · เมื่อเฮลซิงโจมตีปกติ (Auto Attack) ใส่เป้าหมายที่ติดตราประทับจะลบล้างตราออกและระเบิดความเสียหายกายภาพเพิ่มเติม : ความเสียหายกายภาพ : 20–105 ( ตามเลเวล 1–18) (+35% Bonus AD) (+6% / 8% / 10% / 12% ของพลังชีวิตที่หายไปของเป้าหมาย Missing HP ที่เลเวล 1 / 6 / 11 / 16) ■
  - เอฟเฟกต์ภาพและเสียง : เหนือศีรษะศัตรูจะปรากฏตราไม้กางเขนเหล็กสีเงินลุกไหม้ด้วยประกายไฟสีม่วงเมื่อเฮลซิงโจมตีปกติซํ้าตราจะแตกออกเป็นสะเก็ดไฟสีเงินพร้อมเสียงทุบโลหะศักดิ์สิทธิ์ดัง " เค้ง !" สะท้อนกังวาน

Q: Stake Driver ( ตอกลิ่มเงินเสียบวิญญาณ ) เฮลซิงสับกลไกกระบอกส่งแรงดีดส่งลิ่มเงินอาคมขนาดยักษ์พุ่งแหวกอากาศเป็นแนวเส้นตรงเจาะร่างศัตรูตัวแรกที่ขวางทางอย่างรุนแรง
  - ประเภทสกิล : ลูกกระสุน · หลบได้ (Linear Skillshot)
  - ท่วงท่าแอนิเมชัน : เฮลซิงยกแขนขวาขึ้นเล็งกระบอกดีดลิ่มเหล็กตรงไปข้างหน้าเกิดประกายควันดินปืนสีดําปะทุขึ้นก่อนที่ลิ่มเงินยาวจะถูกตอกยิงพุ่งออกไปอย่างรวดเร็วตัวละครเซถอยหลังจากแรงถีบเล็กน้อยขนาดและระยะพื้นที่ (Hitbox):
      · ระยะการยิง (Range): 750 หน่วย
      · ความกว้างลําลิ่ม (Width): 80 หน่วย
      · ความเร็วขีปนาวุธ (Speed): 1200 หน่วย / วินาที ( กระทบศัตรูตัวแรกแล้วหยุดทันที )
  - คูลดาวน์ : 7 / 6.5 / 6 / 5.5 / 5 วินาที
  - ความเสียหายกายภาพ : 75 / 110 / 145 / 180 / 215 (+80% Bonus AD)
  - เอฟเฟกต์เสียง : เสียงดินปืนระเบิดอัดกระบอกดีด " ปัง !" ตามด้วยเสียงแทงทะลุเนื้อ " ฉึก !" ปลายลิ่มทิ้งควันสีเงินจางๆไว้ในอากาศ 

W: Consecrated Volley ( หน้าไม้กลกระหนํ่าสกัด ) ยกหน้าไม้กลแขนกลขึ้นยิงสลักเกาทัณฑ์เคลือบนํ้ามนต์ศักดิ์สิทธิ์พุ่งทะลวงผ่านศัตรูทุกตัวในแนวเส้นทางสร้างความเสียหายชะลอความเร็วและปิดกั้นการสมานบาดแผล
  - ประเภทสกิล : ลูกกระสุน · หลบได้ (Piercing Linear Skillshot)
  - ท่วงท่าแอนิเมชัน : เฮลซิงตวัดมือซ้ายชักหน้าไม้กลออกมาในระดับอกรัวยิงลูกศรโลหะโปร่งแสงที่เคลือบอักขระเวทมนตร์สีฟ้าครามลูกศรพุ่งกรีดอากาศเป็นแนวยาวทะลุผ่านเป้าหมายทั้งหมด
  - ขนาดและระยะพื้นที่ (Hitbox):
      · ระยะการยิง (Range): 700 หน่วย
      · ความกว้างแนวลูกศร (With): 100 หน่วย
      · ความเร็วขีปนาวุธ (Speed): 1300 หน่วย / วินาที
  - คูลดาวน์ : 10 / 9.5 / 9 / 8.5 / 8 วินาที
  - ความเสียหายกายภาพ : 60 / 95 / 130 / 165 / 200 (+60% Bonus AD)
  - ผลดีบัฟ (Debuff):
      · ศัตรูทุกตัวที่โดนลูกศรทะลุผ่านจะติดสถานะ Slow 30 / 32.5 / 35 / 37.5 / 40% นาน 2 วินาที
      · ติดสถานะ Grievous Wounds ( ตัดฮีล ): ลดผลการรักษาและฟื้นฟูเลือดลง 40% เป็นเวลา 5.0 วินาที
  - เอฟเฟกต์เสียง : เสียงกลไกเฟืองหน้าไม้หมุนลั่น " กริ๊ก - แชะ !" ตามด้วยเสียงลูกศรพุ่งเฉือนอากาศเป็นระลอกยาว 

E: Phantom Shift & Reaping Arc ( ย่างก้าวเงาวาร์ปตวัดเกี่ยว ) เฮลซิงสลายตัวกลายเป็นหมอกควันสีดําวาร์ปไปยังจุดเป้าหมายอย่างฉับพลันโดยไม่ได้รับความเสียหายชั่วเสี้ยววินาทีสร้างความเสียหายณจุดปลายทางพร้อมเสริมพลังให้การโจมตีครั้งถัดไปพุ่งเข้าฟันกวาดระยะไกลเป็นรูปครึ่งวงกลม
  - ประเภทสกิล : วาร์ป + อมตะชั่วขณะ ➔ ติดออโต้พุ่งฟันกวาด (Blink/Untargetable ➔ Empowered Cleave Dash)
  - ท่วงท่าแอนิเมชัน :
      · จังหวะวาร์ป : เฮลซิงดึงผ้าคลุมสะบัดห่อหุ้มตัวร่างสลายกลายเป็นกลุ่มหมอกควันดําทมิฬหายตัวและเข้าสู่สภาวะ Untargetable ( ไม่ตกเป็นเป้าหมายและไม่โดนดาเมจใดๆ ) นาน 0.25 วินาทีก่อนจะไปโผล่ณตําแหน่งเป้าหมายระเบิดคลื่นหมอกสร้างดาเมจเล็กน้อย
      · จังหวะโจมตีเสริมพลัง : ใบมีดอาคมของเฮลซิงเรืองแสงสีเงินสว่างจ้าการสั่งโจมตีครั้งถัดไปจะทําให้เฮลซิงพุ่งทะยานเข้าฟันศัตรูจากระยะไกลแล้วตวัดเคียวมีดฟันกวาดเป็นรูปครึ่งวงกลมด้านหน้า
  - ขนาดและระยะพื้นที่ (Hitbox & Range):
      · ระยะวาร์ปสูงสุด (Blink Range): 350 หน่วย
      · ดาเมจตอนวาร์ปไปถึง : รัศมีวงกลม 150 หน่วยรอบจุดที่โผล่
      · ระยะโจมตีพิเศษ (Empowered Attack Range): ระยะโจมตีพุ่งเข้าหาเป้าหมายจะขยายกว้างเท่ากับระยะวาร์ปสูงสุดคือ 350 หน่วย ( พุ่งระยะ 350 หน่วยไปฟันเป้าหมาย )
      · รัศมีฟันกวาดครึ่งวงกลม (Semi-Circle Cleave): รูปครึ่งวงกลม 180 องศาด้านหน้ารัศมีกว้าง 350 หน่วย
      · - คูลดาวน์ : 10 / 9.5/ 9 / 8.5 / 8 วินาที
  - ความเสียหายกายภาพ :
      · ดาเมจจังหวะวาร์ปโผล่ : 30 / 45 / 60 / 75 / 90 (+25% Bonus AD)
      · ดาเมจจังหวะฟันกวาดครึ่งวงกลม : 50 / 80 / 110 / 140 / 170 (+65% Bonus AD)
      · - เอฟเฟกต์เสียง : เสียงผ้าคลุมสะบัดกลืนไปกับสายลม " ฟึ่บ ..." ตามด้วยเสียงฟันกวาดโลหะสะบั้นอากาศ " ชิ้งงง !" 

R: Inquisitor's Iron Maiden ( อาณาเขตขังเดี่ยวพิพากษาอสุรา ) เฮลซิงพุ่งเข้ากระแทกแชมเปี้ยนศัตรูตัวแรกอย่างดุดันก่อนจะถีบตัวดีดถอยหลังออกมาปักโซ่ตรวนและเสาหลักศักดิ์สิทธิ์ปิดล้อมขังเหยื่อไว้ในอาณาเขตโดยที่เหยื่อจะไม่สามารถหลบหนีฮีลเลือดไม่ได้เด็ดขาดและพลังโจมตีลดทอนลง
  - ประเภทสกิล : พุ่งชนแล้วดีดกลับ + ขังเดี่ยวตัดฮีลสมบูรณ์แบบ (Collision Dash-Rebound & Duel Arena Lock)
  - ท่วงท่าแอนิเมชัน :
      · จังหวะพุ่งชน : เฮลซิงพุ่งเป็นเส้นตรงระยะ 500 หน่วยเมื่อปะทะแชมเปี้ยนศัตรูตัวแรกเขาจะใช้ปลายเท้าถีบหน้าอกศัตรูเต็มแรงพร้อมดีดตัวสปริงถอยหลังกลับออกมาเป็นระยะ 250 หน่วย
      · จังหวะกางอาณาเขต : เสาลิ่มเงิน 4 ต้นผุดขึ้นมาจากพื้นดินล้อมรอบตําแหน่งของศัตรูมีโซ่ตรวนเวทมนตร์สีแดงเลือดตรึงเชื่อมกันเป็นกรงอาณาเขตทรงกลม
  - ขนาดและระยะพื้นที่ (Hitbox & Duration):
      · ระยะพุ่งเข้าชน : 500 หน่วย ( ความเร็ว 450 หน่วย / วินาที )
      · ระยะดีดตัวกลับ (Rebound): 250 หน่วยตรงข้ามกับทิศทางที่พุ่งเข้า
      · รัศมีอาณาเขตขังเดี่ยว (Arena Radius): 250 หน่วยรอบจุดศูนย์กลางที่ศัตรูยืนอยู่
      · ระยะเวลาของอาณาเขต : 2.5/3/3.5 วินาที
  - คูลดาวน์ : 60 / 55 / 50 วินาที
  - ความเสียหายกายภาพ : 100 / 200 / 300 (+50% Bonus AD) ( ทําดาเมจในจังหวะถีบปะทะแรก )
  - กลไกการกักขัง (Exclusive Incarceration Mechanism):
      · การล็อกตัวเหยื่อ (Target Confined): ศัตรูตัวที่ถูกสกิลนี้จะไม่สามารถก้าวเดิน , ใช้สกิลพุ่ง (Dash), หรือวาร์ป (Blink) ออกไปนอกขอบเขตกําแพง 375 หน่วยได้เด็ดขาด ( ถือเป็น Impassable Boundary เฉพาะตัวเป้าหมาย )
      · การตัดการรักษา 100% (Absolute Anti-Heal): ตลอดเวลาที่อยู่ในวงเหยื่อจะติดสถานะ Curse of the Inquisitor: ไม่สามารถรับการฟื้นฟูพลังชีวิต (Heal), การดูดเลือด (Lifesteal/Omnivamp), หรือการฟื้นฟูเลือดตามธรรมชาติใดๆได้เลย (0% Healing)
      · ลดทอนพลังรุก (Suppressed Offense): พลังความเสียหายที่เหยื่อสร้างขึ้นทั้งหมด (Damage Output) จะลดลง 10 / 12.5 / 15% ตราบใดที่ยังถูกขังอยู่ในวง
      · ผลต่อยูนิตอื่น (Free Passage): พันธมิตรของเฮลซิงและแชมเปี้ยนศัตรูตัวอื่นๆสามารถเดินผ่านเข้า - ออกขอบเขตนี้ได้อย่างอิสระ ( ไม่ใช่กําแพงทึบสําหรับคนอื่น )
  - เอฟเฟกต์ภาพและเสียง : เสียงพุ่งชน " ตึง !" ตามด้วยเสียงโซ่เหล็กลากตรึงพื้นดิน " แคร้งๆๆ !" อาณาเขตมีละอองไอเวทมนตร์สีแดงเข้มพวยพุ่งศัตรูที่พยายามแตะขอบเขตจะถูกไฟฟ้าอาคมผลักสะท้อนกลับเข้ามาในวงแนวทางการเล่นและจังหวะคอมโบ (Playstyle Concept)
  - Assassination Isolation (R ➔ E ➔ W ➔ Q ➔ Auto): ล็อกเป้าตัวหลักด้วย R พุ่งชนแล้วดีดตัวออกมาขังเหยื่อไว้ในวงตัดฮีล 100% จากนั้นกด E วาร์ปหลบสกิลสวนกลับพร้อมรับสเต็ปฟันกวาดสาด W หน้าไม้ตัดฮีลสโลว์ซํ้าตามด้วย Q ตอกลิ่มเงินระยะประชิดแล้วปิดฉากด้วยการโจมตีปกติระเบิด Passive ตามสัดส่วนเลือดที่หายไปของศัตรู
  - Hit & Run Skirmish (Q ➔ E1 วาร์ป ➔ E2 ฟันกวาด ➔ W สโลว์ถอย ): ใช้ Q ตอดเลือดระยะกลางเพื่อแปะตรา Passive จากนั้นกด E วาร์ปหลบจังหวะสวนของศัตรูแล้วใช้ระยะฟันกวาด 350 หน่วยพุ่งฟันระเบิดตรา Passive ก่อนจะสาด W เพื่อสโลว์ศัตรูแล้วเดินฉากหลบออกมาอย่างปลอดภัย ### **Wolf ( วูล์ฟ ) — The Apex Predator ( หมาป่าทมิฬจอมเขมือบ ) [Adjusted]** * ** สายการเล่น (Role):** Juggernaut / AD Fighter ( ไฟต์เตอร์ระยะประชิดยิ่งเป้าหมายเลือดน้อยยิ่งสังหารเร็วเสริมการโจมตีเพื่อฉีกเกราะชาร์จคํารามเปิดจังหวะให้ศัตรูตอบสนองและมีท่าไม้ตายเขมือบซากรีเซ็ตสกิลต่อเนื่องคูลดาวน์สั้น ) * ** ระบบทรัพยากร : ** ไม่มีมานา (Cooldown-based) * ** ระยะโจมตีปกติ (Attack Range):** 175 หน่วย ( ระยะประชิดใช้กรงเล็บและเขี้ยว ) (Jungle) --- ### ** สเตตัสพื้นฐาน (Base Stats)** * ** พลังชีวิต (HP):** 630 (+105 ต่อเลเวล ) * ( เลเวล 13: 1,890 | เลเวล 18: 2,415)* * ** ฟื้นฟูพลังชีวิต (HP Regen):** 8.5 (+0.8 ต่อเลเวล ) * ( เลเวล 13: 18.1 | เลเวล 18: 22.1)* * ** พลังโจมตี (AD):** 65 (+3.8 ต่อเลเวล ) * ( เลเวล 13: 110.6 | เลเวล 18: 129.6)* * ** ความเร็วโจมตี (Attack Speed):** 0.65 (+0.022 ต่อเลเวล ) * ( เลเวล 13: 0.91 | เลเวล 18: 1.02)* * ** เกราะ (Armor):** 37 (+4.2 ต่อเลเวล ) * ( เลเวล 13: 87.4 | เลเวล 18: 108.4)* * ** ต้านทานเวท (MR):** 32 (+2.05 ต่อเลเวล ) * ( เลเวล 13: 56.6 | เลเวล 18: 66.85)* * ** ความเร็วเคลื่อนที่ (MS):** 335 หน่วย --- ### **

W: Stalker’s Pounce ( ย่องเงาตะปบเหยื่อ ) ** * **Passive — Blood Scent ( กลิ่นสาบผู้บาดเจ็บ ): ** * ได้รับความเร็วเคลื่อนที่พื้นฐานเพิ่มขึ้น **+10 / 12.5 / 15 / 17.5 / 20%** * หากเคลื่อนที่มุ่งหน้าเข้าหาแชมเปี้ยนศัตรูที่มีเลือดตํ่ากว่า 50% ในระยะ 1,200 หน่วยโบนัสนี้จะเพิ่มเป็น 3 เท่า (**+30 / 37.5 / 45 / 52.5 / 60%**) * **Active — Pounce from Darkness ( กระโจนจากเงามืด ): ** * Wolf สลายร่างเข้าสู่สภาวะ ** ล่องหน (Invisibility)** เป็นเวลา **1.75 วินาที ** * การกดโจมตีปกติครั้งถัดไปภายในช่วงล่องหน ( หรือภายใน 1 วินาทีหลังหลุดล่องหน ) จะเป็นการ ** กระโจนพุ่งลอยตัวเข้าใส่จุดเป้าหมาย ** ( สกิลเล็งตกพื้นมีเงาเตือนศัตรูสามารถเดิน / พุ่งหลบได้ ) * ** ประเภทสกิล : ** บัฟตัวเอง ➔ วงกลมบนพื้น · มีหน่วง — หลบได้ * ** ท่วงท่าแอนิเมชัน : ** กลายสภาพเป็นเงาดําเลือนรางเมื่อกดโจมตีจะกระโดดลอยตัวข้ามอากาศไปตะปบพื้นจุดเป้าหมาย ( หน่วงเวลาลอย 0.35 วินาทีมีวงเตือนบนพื้น ) * ** ขนาดและระยะพื้นที่ (Hitbox):** * ** ระยะกระโจน (Leap Range):** **500 หน่วย ** * ** รัศมีจุดตกกระทบ (Landing Radius):** **225 หน่วย ** * ** คูลดาวน์ : ** 14 / 13 / 12 / 11 / 10 วินาที * ** ความเสียหายกายภาพ : ** **70 / 110 / 150 / 190 / 230 (+70% Bonus AD)** * ** เอฟเฟกต์เสียง : ** เสียงลมหายใจหอบเบาๆขณะล่องหนตามด้วยเสียงตะปบพื้นดิน " ตึง !" --- ### **

Passive: Spider's Traverse ( ไต่ใยข้ามมิติ & เขี้ยวพิษนิทาน ) ** อนันซีผู้ร้อยเรียงโครงข่ายแห่งผืนพิภพสามารถใช้ขาแมงมุมไต่ก้าวผ่านสิ่งกีดขวางและกําแพงทุกรูปแบบได้อย่างอิสระพร้อมทั้งอาบพิษเวทมนตร์ลงบนการโจมตีปกติ * ** กลไกการเดินผ่านกําแพง (Terrain Phasing):** * อนันซีสามารถ ** เดินทะลุสิ่งกีดขวางและกําแพงตามธรรมชาติรวมถึงกําแพงที่แชมเปี้ยนสร้างขึ้นได้ทั้งหมด ** ( เช่นกําแพงหินฉาก , กําแพงของ Porky, กําแพง Anivia) * ** เงื่อนไขความสมดุล : ** * เมื่อเดินเข้าไปในเนื้อกําแพงอนันซีจะได้รับความเร็วเคลื่อนที่คงที่และมองเห็นวิสัยทัศน์รอบขอบกําแพงระยะ 450 หน่วย * อนันซีสามารถอยู่ในกําแพงได้ต่อเนื่องสูงสุด **3.0 วินาที ** หากอยู่ครบเวลาจะถูกดันตัวออกมายังขอบกําแพงฝั่งที่ใกล้ที่สุดทันที * หากได้รับความเสียหายจากแชมเปี้ยนศัตรูขณะอยู่ในกําแพงระยะเวลาคงเหลือจะลดลง 50% ทันที * คูลดาวน์การเดินเข้ากําแพงใหม่ : **8 / 7 / 6 วินาที ** ( ที่เลเวล 1 / 7 / 13) * ** โบนัสดาเมจติดการโจมตีปกติ (On-Hit Magic Damage):** * การโจมตีปกติทุกครั้งจะสร้างความเสียหายเวทเพิ่มเติม : **15–65 ( ตามเลเวล 1–18) (+20% AP)** * ** ท่วงท่าแอนิเมชัน : ** เมื่อเข้าใกล้ขอบกําแพงอนันซีจะยกขาแมงมุมทั้งสี่ขาปักเกาะและเลื้อยไต่เข้าไปในเนื้องานหินอย่างคล่องแคล่วมีประกายเส้นใยไหมสีทองระยิบระยับลากตามหลัง --- ### **

Q: Gourd of Wit ( นํ้าเต้าปัญญาฟาดปฐพี ) ** อนันซีชักใยดึงผลนํ้าเต้ามนตราขนาดใหญ่ขึ้นสู่ฟากฟ้าก่อนจะกระชากทุ่มลงมากระแทกพื้นดินณจุดเป้าหมายอย่างรุนแรงระเบิดเศษเปลือกและคลื่นเวทมนตร์บดขยี้ศัตรูในบริเวณ * ** ประเภทสกิล : ** วงกลมบนพื้น · มีหน่วง — หลบได้ (Delayed Ground AoE Burst) * ** ท่วงท่าแอนิเมชัน : ** อนันซีสะบัดข้อมือชูขึ้นฟ้ากระตุกสายใยไหมโปร่งแสงมีเงาผลนํ้าเต้ายักษ์สีม่วงทองปรากฏขึ้นเหนือจุดเล็งหน่วงเวลา 0.35 วินาทีก่อนจะทุ่มฟาดกระแทกลงบนพื้นดินจนแตกระเบิด * ** ขนาดและระยะพื้นที่ (Hitbox):** * ** ระยะการสั่งร่าย (Cast Range):** **800 หน่วย ** * ** รัศมีจุดตกกระทบ (AoE Radius):** **250 หน่วย ** * ** เวลาหน่วงก่อนระเบิด (Delay):** **0.35 วินาที ** * ** คูลดาวน์ : ** 7 / 6.5 / 6 / 5.5 / 5 วินาที * ** ความเสียหายเวท : ** **80 / 125 / 170 / 215 / 260 (+75% AP)** * ** เอฟเฟกต์เสียง : ** เสียงเส้นใยตึงตัว " ฟึ่บ !" ตามด้วยเสียงนํ้าเต้ากระแทกพื้นแตกดัง " ตึ้ง - เพล้ง !!" ประกายเวทมนตร์สีทองฟุ้งกระจาย --- ### **

W: Tangled Puppetry ( ใยชะตาร้อยสลักร่าง ) ** ยิงสายใยไหมเส้นตรงใส่ศัตรูสร้างความเสียหายและสโลว์หากยิงโดนจะปลดล็อกให้กดใช้ซํ้าเพื่อยิงเส้นใยที่สองโดยมีผลลัพธ์แยกตามเป้าหมายที่โดน * ** ประเภทสกิล : ** ลูกกระสุน · หลบได้ ➔ ยิงซํ้าเล็งเป้า (Two-Cast Skillshot Tether) * ** คูลดาวน์ : ** 13 / 12 / 11 / 10 / 9 วินาที ( เริ่มนับหลังจากการร่ายครั้งที่ 2 สิ้นสุดลงหรือเมื่อหมดเวลา 3.5 วินาที ) * ** ระยะเวลาการกดซํ้า : ** มีเวลา **3.5 วินาที ** ในการกดร่ายครั้งที่ 2 * ** การร่ายครั้งที่ 1 (First Thread):** * ยิงใยอาคมเป็นเส้นตรงระยะ **850 หน่วย ** ( ความกว้างลําใย **110 หน่วย **, ความเร็วกระสุน 1,750 หน่วย / วินาที ) * ทําความเสียหายเวทใส่เป้าหมายแรก : **50 / 75 / 100 / 125 / 150 (+40% AP)** * ** ผลสโลว์ : ** ลดความเร็วเคลื่อนที่เป้าหมาย **35%** นาน 1.5 วินาทีพร้อมแปะปลายสายใยไว้ที่ร่างเหยื่อ * ** การร่ายครั้งที่ 2 (Second Thread Recast):** * ยิงสายใยเส้นที่สองในลักษณะเดิมออกไป : * ** กรณีที่ 1 — ยิงโดนศัตรูตัวเดิม (Same Target Root):** * สร้างความเสียหายเวทเพิ่มเติม 50% ของดอกแรก : **25 / 37.5 / 50 / 62.5 / 75 (+20% AP)** * พันธนาการร่างศัตรู : ติดสถานะ **Root ( ตรึงเท้าเดินไม่ได้ ) เป็นเวลา 1.25 / 1.4 / 1.55 / 1.7 / 1.85 วินาที ** * ** กรณีที่ 2 — ยิงโดนศัตรูอีกตัว (Different Targets Collision):** * สร้างความเสียหายเวท **50 / 75 / 100 / 125 / 150 (+40% AP)** ใส่เป้าหมายที่สอง * ** กลไกกระชากชนกัน (Snap Pull):** เส้นใยจะกระตุกดึงศัตรูทั้งสองตัวให้ ** พุ่งลอยเข้าหากันณจุดกึ่งกลางระหว่างทั้งสอง (Midpoint Pull)** * ** เมื่อร่างทั้งสองกระแทกกัน (Collision Impact):** ระเบิดดาเมจเวทเพิ่มเติมแก่ทั้งสองตัว **60 / 95 / 130 / 165 / 200 (+55% AP)** และติดสถานะ **Stun ( สตัน ) เป็นเวลา 0.75 / 0.85 / 0.95 / 1.05 / 1.15 วินาที ** * ** ท่วงท่าแอนิเมชัน : ** อนันซีสะบัดนิ้วดีดเส้นใยสีม่วงประกายทองพุ่งออกไปจังหวะดึงศัตรูสองตัวชนกันอนันซีจะกําหมัดแล้วกระชากแขนเข้าหาอกศัตรูทั้งสองจะถูกดึงลอยมาชนหน้าผากกันเสียงดังสนั่น --- ### **

E: Sticky Web Trap ( พ่นใยม่านกักสัญจร ) ** อนันซีสะบัดอกพ่นม่านใยแมงมุมเหนียวหนืดออกมาเป็นรูปกรวยด้านหน้าทําดาเมจเวททันทีและทิ้งผืนใยเคลือบพื้นดินค้างไว้ศัตรูที่อยู่ในอาณาเขตจะติดสโลว์อย่างหนักและถูกปิดกั้นการใช้สกิลเคลื่อนที่รวมถึงไม่สามารถเร่งความเร็วเดินได้ * ** ประเภทสกิล : ** กรวยด้านหน้า ➔ โซนค้างที่ · เดินออกได้ (Cone Burst into Grounded Web Field) * ** ท่วงท่าแอนิเมชัน : ** อนันซีย่อตัวลงแล้วพ่นละอองใยแมงมุมสีขาวอมม่วงแผ่กว้างออกไปข้างหน้าผืนดินในระยะจะถูกปกคลุมด้วยรังใยหนาแน่นมีใยแมงมุมผูกโยงระโยงระยางตามพื้น * ** ขนาดและระยะพื้นที่ (Hitbox & Duration):** * ** ระยะพ่น (Range):** **600 หน่วย ** * ** มุมกว้างของกรวย (Cone Angle):** **60 องศา ** ด้านหน้า * ** ระยะเวลาที่ใยค้างบนพื้น : ** **3.0 วินาที ** * ** คูลดาวน์ : ** 12 / 11.5 / 11 / 10.5 / 10 วินาที * ** ความเสียหายเวท ( จังหวะพ่นโดนแรก ): ** **60 / 95 / 130 / 165 / 200 (+50% AP)** * ** ผลกระทบของผืนใย (Web Zone Effects):** * ** ผลสโลว์ : ** ศัตรูที่เหยียบหรือยืนอยู่ในใยจะติด **Slow 35 / 40 / 45 / 50 / 55%** * ** สถานะ Grounded ( ตรึงพื้น ): ** ศัตรู ** ไม่สามารถกดใช้สกิลประเภท Dash, Leap, Blink หรือ Teleport ใดๆได้เลย ** ตราบใดที่ยังยืนอยู่บนใย * ** สถานะ Cripple ( ระงับความเร็ว ): ** ** ปิดกั้นบัฟเร่งความเร็วเคลื่อนที่ทั้งหมด (Move Speed Buffs Nullified)** — สกิลหรือไอเทมที่เพิ่มความเร็วเดินจะไม่ส่งผลใดๆกับศัตรูในเขตใยนี้ * ** เอฟเฟกต์เสียง : ** เสียงพ่นของเหลวเหนียวหนืด " ฟู่รรร !" ตามด้วยเสียงเดินยํ่ากาวเหนียวหนืด " จ๊วบ - จ๊วบ " --- 

R: Venom of Paranoia ( คลื่นมึนเมามหาทรยศ ) [Adjusted] อนันซีปลดปล่อยเขี้ยวพิษอ้าปากพ่นมวลหมอกควันพิษประสาทหลอนสีม่วงเข้มขนาดมหึมาม้วนตัวคืบคลานไปข้างหน้าอย่างช้าๆเป็นแนวกว้างครอบคลุมทั้งสนามรบแม้ตัวคลื่นจะไม่สร้างความเสียหายโดยตรงแต่ศัตรูทุกคนที่ถูกคลื่นพิษกลืนกินจะสูญเสียสติสัมปชัญญะเกิดอาการคลุ้มคลั่งและหันกลับไปทําร้ายพวกเดียวกันเองทันทีประเภทสกิล : ลูกกระสุน / คลื่นกวาดขนาดยักษ์ · เคลื่อนช้า — หลบได้ · ท่าไม้ตาย (Pure Utility & Mass Berserk Wave) ท่วงท่าแอนิเมชัน : อนันซียกขาแมงมุมทั้ง 4 ขาขึ้นกางสยายเต็มตัวเอนหลังสูดอากาศลึกก่อนจะอ้าปากพ่นกําแพงคลื่นหมอกควันพิษสีม่วงดําขนาดมหึมาทรงคลื่นม้วนตัวดั่งสึนามิพิษที่ค่อยๆแผ่กวาดไปข้างหน้าอย่างช้าๆศัตรูที่ถูกคลื่นซัดผ่านจะไม่ได้รับบาดแผลทางกายภาพแต่จะมีกลุ่มควันหมอกสีม่วงหนาทึบเกาะคลุมศีรษะดวงตากลายเป็นสีแดงกํ่าหันไปเล็งคมอาวุธใส่เพื่อนร่วมทีมทันทีขนาดและระยะพื้นที่ (Hitbox & Wave Speed): ระยะการเคลื่อนที่ (Range): 1,050 หน่วย ( ปรับให้พุ่งไปได้ไกลขึ้นมากจากเดิม 750 หน่วยเพื่อใช้เปิดไฟต์หรือปิดทางถอยจากระยะปลอดภัย ) ความกว้างหน้าคลื่น (Wave Width): 650 หน่วย ( ขยายกว้างขึ้นอย่างมหาศาลจากเดิม 450 หน่วยสามารถปิดพื้นที่ทางเดินในป่าช่องแคบแม่นํ้าหรือกวาดคลุมทั้งเลนได้มิด ) ความเร็วการเคลื่อนที่ของคลื่น (Projectile Speed): 850 หน่วย / วินาที ( ปรับลดความเร็วลงอย่างเห็นได้ชัดจากเดิม 1,350 หน่วย / วินาทีทําให้คลื่นลอยคืบคลานไปช้าๆเพื่อเปิดโอกาสให้ศัตรูมีเวลาตอบสนองแฟลชข้ามหรือรีบเดินฉากหลบ ) คูลดาวน์ : 55 / 50 / 45 วินาทีความเสียหาย : ไม่มีความเสียหาย (0 Damage) — เปลี่ยนเป็นสกิล Utility & Hard CC ควบคุมจังหวะไฟต์ 100% ผลควบคุมพิเศษ — Madness / Berserk ( มึนเมาคลั่งสังหารพวกพ้อง ): ศัตรูทั้งหมดที่สัมผัสโดนแนวคลื่นหมอกพิษจะติดสถานะ Berserk ( บ้าคลั่ง ) เป็นเวลา 1.25 / 1.5 / 1.75 วินาทีพฤติกรรมขณะติดสถานะ : ผู้เล่นฝั่งศัตรูจะไม่สามารถบังคับการเดินร่ายสกิลหรือกดใช้ไอเทมใดๆได้แชมเปี้ยนศัตรูที่ติดสถานะจะได้รับความเร็วโจมตี +100% และบังคับเลี้ยวไปโจมตีปกติ (Auto Attack) ใส่ยูนิตพันธมิตรของตนเองที่อยู่ใกล้ที่สุดทันที ( ความเสียหายคํานวณตามพลังโจมตีและเอฟเฟกต์ On-Hit ของตัวศัตรูเอง ) ลําดับการเลือกเป้าหมายตีพวกเดียวกัน : Passive: Cinder Scourge ( มหาเพลิงผลาญผงถ่าน ) ** เปลวไฟของอิฟริตเป็นไฟบรรพกาลที่ไม่ดับมอดลงง่ายๆทุกการโจมตีปกติและสกิลสร้างความเสียหายจะจุดไฟเผาร่างเหยื่ออย่างต่อเนื่อง * ** กลไกการทํางาน : ** * เมื่อสร้างความเสียหายด้วยการโจมตีปกติหรือสกิล (Q, W, E, R) ใส่ศัตรูจะติดสถานะ **Ignited ( เผาไหม้ ) ** เป็นเวลา **3.0 วินาที ** * สร้างความเสียหายเวททุกๆ **0.5 วินาที ** ( ทํางาน 6 ระลอก ): * ความเสียหายต่อระลอก : **3–15 ( ตามเลเวล 1–18) (+3.5% AP)** * * ( ความเสียหายรวมตลอด 3 วินาที : **18–90 +21% AP**)* * การโจมตีหรือโดนสกิลซํ้าจะรีเฟรชระยะเวลา 3 วินาทีใหม่ทันที * ** ท่วงท่าแอนิเมชัน : ** ศัตรูที่โดนจะมีเปลวไฟสีส้มแดงลุกท่วมตัวทิ้งสะเก็ดขี้เถ้าและควันดําตามหลังขณะเดิน --- ### **

Q: Pyroclastic Orb ( ลูกเพลิงอัดระเบิดปฐพี ) ** อิฟริตควบแน่นมวลไฟในฝ่ามือแล้วซัดลูกบอลเพลิงขนาดยักษ์พุ่งเป็นเส้นตรงเมื่อปะทะศัตรูตัวแรกหรือสุดระยะทางลูกเพลิงจะระเบิดออกอย่างรุนแรงสร้างความเสียหายเวทแก่ศัตรูทุกคนในรัศมีจุดระเบิด * ** ประเภทสกิล : ** ลูกกระสุน · วงกลมระเบิดปลายทาง · หลบได้ (Linear Skillshot with AoE Detonation) * ** ท่วงท่าแอนิเมชัน : ** อิฟริตเอี้ยวตัวไปข้างหลังดึงลูกไฟแมกมาขนาดใหญ่ขึ้นมาไว้ข้างเอวแล้วผลักสองฝ่ามือยิงลูกไฟพุ่งทะยานแหวกอากาศไปข้างหน้าเมื่อชนศัตรูหรือสุดระยะทางจะแตกเป็นคลื่นระเบิดทรงกลมกระจายออก * ** ขนาดและระยะพื้นที่ (Hitbox):** * ** ระยะการยิง (Range):** **850 หน่วย ** * ** ความกว้างลํากระสุน (Missile Width):** **110 หน่วย ** ( ความเร็วกระสุน 1,750 หน่วย / วินาที ) * ** รัศมีการระเบิดเมื่อโดน (Detonation Radius):** **225 หน่วย ** * ** คูลดาวน์ : ** 7 / 6.5 / 6 / 5.5 / 5 วินาที * ** ความเสียหายเวท : ** **80 / 125 / 170 / 215 / 260 (+75% AP)** * ** เอฟเฟกต์เสียง : ** เสียงเปลวไฟพุ่งแหวกอากาศ " ฟิ้ววว !" ตามด้วยเสียงระเบิดกัมปนาท " ตูม !!" --- ### **

W: Combustive Blast ( ระเบิดเพลิงผลาญมนตรา ) ** สั่งจุดชนวนระเบิดมวลอากาศธาตุไฟณพื้นที่เป้าหมายอย่างฉับพลันสร้างความเสียหายเวทแก่ศัตรูในวงและเผาผลาญเกราะอาคมทําให้พลังต้านทานเวทของศัตรูที่โดนลดลงอย่างรุนแรง * ** ประเภทสกิล : ** วงกลมบนพื้น · มีหน่วงเล็กน้อย — หลบได้ (Targeted Ground Burst & MR Shred) * ** ท่วงท่าแอนิเมชัน : ** อิฟริตกําหมัดแน่นแล้วกระตุกข้อมือขึ้นฟ้าบนพื้นดินจุดเป้าหมายจะเกิดรอยแตกสีแดงส้มสว่างวาบขึ้นมาหน่วงเวลา 0.25 วินาทีก่อนที่เสาเพลิงลาวาจะระเบิดพุ่งขึ้นมาจากใต้ดินสู่ท้องฟ้า * ** ขนาดและระยะพื้นที่ (Hitbox):** * ** ระยะการสั่งร่าย (Cast Range):** **725 หน่วย ** * ** รัศมีแรงระเบิด (AoE Radius):** **250 หน่วย ** * ** คูลดาวน์ : ** 11 / 10.5 / 10 / 9.5 / 9 วินาที * ** ความเสียหายเวท : ** **70 / 105 / 140 / 175 / 210 (+60% AP)** * ** ผลลดต้านทานเวท (Magic Resist Shred):** * ศัตรูที่โดนแรงระเบิดจะถูก ** ลดต้านทานเวท (MR) ลง 15 / 17.5 / 20 / 22.5 / 25%** เป็นเวลา **3.5 วินาที ** * ** เอฟเฟกต์เสียง : ** เสียงเสียงประทุใต้ดิน " กึก !" ตามด้วยเสียงเสาเพลิงระเบิดพวยพุ่ง " บึ้มมม !!" --- ### **

E: Trail of Cinders ( พรมเพลิงกาลเบิกทาง ) ** อิฟริตตวัดมือฟาดคลื่นไฟลงสู่พื้นปลดปล่อยร่องผืนดินเพลิงลาวาทอดยาวเป็นแนวตรงไปข้างหน้าสร้างความเสียหายเวทแก่ศัตรูที่ยืนขวางและทิ้งผืนไฟเผาไหม้ค้างไว้บนพื้นดินอย่างต่อเนื่อง * ** ประเภทสกิล : ** โซนค้างที่แนวยาว · ลงทันที — หลบไม่ได้ (Linear Fire Carpet Zone) * ** ท่วงท่าแอนิเมชัน : ** อิฟริตลอยตัวขึ้นสูงเล็กน้อยกวาดแขนซ้ายจากล่างขึ้นบนแผ่นดินตรงหน้าแตกระแหงเป็นร่องลึกแนวยาวมีลาวาและเปลวเพลิงสีแดงอมส้มลุกโชนตลอดแนวร่องดิน * ** ขนาดและระยะพื้นที่ (Hitbox & Duration):** * ** ระยะความยาวของแนวไฟ (Length):** **850 หน่วย ** * ** ความกว้างของแนวไฟ (Width):** **160 หน่วย ** * ** ระยะเวลาที่พื้นไฟค้างอยู่ : ** **3.5 วินาที ** * ** คูลดาวน์ : ** 12 / 11.5 / 11 / 10.5 / 10 วินาที * ** ความเสียหายจังหวะแรก (Initial Impact):** * ศัตรูที่ยืนอยู่ในแนวร่องดินขณะปล่อยสกิลจะโดนดาเมจทันที : **60 / 90 / 120 / 150 / 180 (+50% AP)** * ** ความเสียหายเผาไหม้บนพื้น (Lingering Zone DoT):** * ศัตรูที่เดินผ่านหรือยืนแช่อยู่บนผืนไฟจะได้รับความเสียหายเวททุกๆ **0.5 วินาที **: **15 / 22.5 / 30 / 37.5 / 45 (+15% AP)** * * ( หากยืนแช่ตลอด 3.5 วินาทีโดนดาเมจเผารวมสูงสุด 105 / 157.5 / 210 / 262.5 / 315 +105% AP)* * ** เอฟเฟกต์เสียง : ** เสียงผืนดินฉีกแยก " ครืนนน !" ตามด้วยเสียงไฟลุกโชนต่อเนื่อง " ซู่ๆๆ ..." --- ### **

R: Cataclysmic Firestorm ( มหาวาตภัยเพลิงผลาญภพ ) ** อิฟริตปลุกพลังต้นกําเนิดของญินน์สร้างพายุทอร์นาโดเพลิงขนาดยักษ์หมุนวนขึ้นณพื้นที่เป้าหมายพายุเพลิงขนาดมหึมาจะค่อยๆเคลื่อนตัวมุ่งหน้าเข้าหาแชมเปี้ยนศัตรูที่ใกล้ที่สุดอย่างช้าๆเผาผลาญศัตรูทุกคนที่อยู่ข้างในเป็นระลอกพร้อมสร้างแรงต้านอากาศชะลอความเร็วของเหยื่อ * ** ประเภทสกิล : ** โซนพายุเคลื่อนที่ช้าตามเป้าหมาย · ท่าไม้ตาย (Target-Tracking Moving Giant AoE) * ** ท่วงท่าแอนิเมชัน : ** อิฟริตสยายแขนสองข้างกว้างแหงนหน้าคํารามกู่ก้องเสาพายุหมุนเพลิงบรรพกาลขนาดยักษ์ม้วนตัวพวยพุ่งขึ้นจากพื้นดินสู่ท้องฟ้าลมพายุหมุนกวาดเศษหินและประกายไฟวนเป็นวงกว้างจากนั้นพายุจะเริ่มเคลื่อนตัวคืบคลานเข้าหาแชมเปี้ยนศัตรูอย่างช้าๆดั่งภัยพิบัติที่ไม่อาจหยุดยั้ง * ** ขนาดและระยะพื้นที่ (Hitbox & Movement Speed):** * ** ระยะการสั่งร่ายจุดเริ่มต้น (Cast Range):** **700 หน่วย ** * ** รัศมีของพายุหมุน (Vortex Radius):** **425 หน่วย ** ( วงกว้างมหึมาปิดช่องทางเดินในป่าหรือหน้าป้อมได้ทั้งเลน ) * ** ความเร็วการเคลื่อนที่ของพายุ : ** **250 หน่วย / วินาที ** ( เคลื่อนที่ช้าๆมุ่งหน้าเข้าหาแชมเปี้ยนศัตรูที่อยู่ใกล้ที่สุดโดยอัตโนมัติ ) * ** ระยะเวลาแสดงผล (Duration):** **5.0 วินาที ** * ** คูลดาวน์ : ** 50 / 45 / 40 วินาที * ** ความเสียหายและการสโลว์ (Storm Effects):** * ศัตรูที่อยู่ภายในรัศมีพายุเพลิงจะได้รับความเสียหายเวทต่อเนื่องทุกๆ **0.5 วินาที ** ( ทํางานสูงสุด 10 ระลอก ): * ความเสียหายต่อระลอก : **30 / 45 / 60 (+15% AP)** * * ( หากติดอยู่ในพายุครบ 5 วินาทีโดนดาเมจรวมสูงสุด **300 / 450 / 600 (+150% AP)**)* * ** ผลสโลว์เล็กน้อย (Minor Slow):** ศัตรูที่อยู่ข้างในพายุจะติด **Slow 20 / 25 / 30%** ตราบใดที่ยังอยู่ข้างใน ( ทําให้เดินหนีออกจากขอบพายุได้ยากขึ้น ) * ** เอฟเฟกต์เสียง : ** เสียงพายุหมุนหวีดหวิวผสานเสียงเปลวไฟโหมกระหนํ่า " วู่ววว - ซู่ววว !!" ดังก้องทั่วสนามรบ --- ### ** แนวทางการเล่นและจังหวะคอมโบ (Playstyle & Burst Combos)** * **The Resistance Shred Burst (W ➔ E ➔ Q ➔ Auto):** * เปิดด้วย **W (Combustive Blast)** เพื่อระเบิดลดเกราะเวท (MR Shred) ศัตรูลง 25% * สาด **E (Trail of Cinders)** เป็นแนวยาวทันทีเพื่อทําดาเมจและบีบทางเดิน * ยิง **Q (Pyroclastic Orb)** อัดเข้าไปตรงๆเนื่องจากศัตรูโดนลด MR อยู่ดาเมจระเบิดของ Q จะรุนแรงมหาศาล * ปิดด้วยการโจมตีปกติ 1 ครั้งเพื่อรีเฟรชพิษเผาของ Passive * **Teamfight Zoning & Choke-Point Annihilation (R ➔ W ➔ E ➔ Q):** * ในจังหวะปะทะทีมไฟต์โดยเฉพาะจุดแคบอย่างหน้าแม่นํ้าหรือทางเดินในป่าให้เปิด **R ( พายุไฟยักษ์ ) ** วางดักตรงกลางวงพายุจะค่อยๆเคลื่อนตัวเข้าหาศัตรูและสโลว์ 30% บังคับให้ศัตรูแตกขบวน * ใช้ **W** ระเบิดลด MR กลางดงที่ศัตรูกําลังพยายามเดินหนีพายุแล้วปู **E** เป็นพรมไฟซ้อนทับเส้นทางหนีทําให้ศัตรูต้องเดินเหยียบไฟพร้อมโดนพายุ R กวาดตามหลัง * สแปม **Q** ยิงเก็บกวาดตัวที่เลือดเหลือน้อยจากระยะปลอดภัย
