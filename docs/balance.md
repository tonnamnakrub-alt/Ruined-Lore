# บาลานซ์ไอเทม — ใบสรุปไว้จูนเอง

สร้างจาก `_balance.mjs` (ตีราคาค่าสถานะ) + `_power.mjs` (% ชนะจริง) รันใหม่ได้ทุกเมื่อ

- **คุ้ม%** = มูลค่าค่าสถานะ ÷ ราคาขาย · เกณฑ์: มีพาสซีฟ ~95-100% · ค่าสถานะล้วน ~105-110%
- **ชนะ%** = แจกไอเทมให้ทีมน้ำเงินทั้ง 5 คน แล้วนับ % ชนะทีมแดงที่ซื้อของเท่ากัน (50% = ไม่มีผล)
- **ชนะ% เทียบข้ามสายไม่ได้** — ของ AP ที่แจกให้ตัว AD ด้วยจะดูอ่อนเกินจริง ใช้เทียบภายในสายเดียว
- ตัวเลขทั้งคู่มีความคลาดเคลื่อน ต้องต่างกันเยอะจริงถึงจะเชื่อได้
